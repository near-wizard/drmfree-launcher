# Code of Conduct

Be respectful, be constructive, assume good faith. Disagreements
about code and direction are normal and welcome — personal attacks,
harassment, or discrimination are not tolerated in issues, PRs, or any
other project space.

Violations can be reported by opening an issue or contacting the
maintainer directly. Reports will be handled case-by-case; repeated or
severe violations result in removal from the project's spaces.
